# 产品目标与边界

## 我们要构建什么

Loom 是一个本地优先、能够持续执行和恢复的 Agent 开发工作台。用户掌握仓库、模型连接与凭据；Loom 保存开发目标、计划、变更和验证证据，让开发工作在对话、页面断开及进程重启之后仍可继续。

首个用户是星宇。第一阶段服务单用户、单台开发机上的真实代码仓库；先验证 feature / debug，再扩展架构设计、补全实现、重构和交付准备。

## 一次完整的使用

1. 选择仓库，读取 `AGENTS.md`、当前分支、已有改动与测试入口。
2. 选择连接与模型：内置 endpoint + API key、自定义 endpoint，或符合条件的 ChatGPT 订阅登录。
3. 描述目标，确认可操作的验收行为；能自动发现的信息由系统发现。
4. Agent 在明确工作范围内规划和实现，界面显示阶段、当前动作、diff、验证与剩余事项。
5. 用户可补充约束、请求停止或继续；中断恢复时先核对工作区与未完成工具效果。
6. 输出可审阅的代码和证据；外部发布按已有授权执行。

## 核心价值

- 持续工作：状态保存在本地存储中，聊天历史不是唯一依据。
- 自主推进：已经授权的可逆工作连续执行；只询问影响结果的必要信息。
- 可核对的完成：测试结果绑定具体 revision 和工作树内容，审查后发生修改会使受影响证据失效。
- 可选择的模型：连接、认证和模型独立配置，各阶段可以使用用户指定的 profile。
- 可控成本：限制整个任务树的耗时、并发、轮数与可用 token/金额预算；没有真实用量的数据保持未知。

## 运行时与入口

直接内嵌 `pi-durable`，用隔离 conversation 承担按需职责；不依赖 Hermes、OpenCode、Codex CLI 或 Claude Code 驱动开发流程。Antigravity 仅允许可选外部工具接入。

先交付 CLI，再提供本地 Web 工作台。关闭客户端不结束服务端任务；暂停、取消和恢复必须有明确的持久状态。远程消息入口、桌面封装与多设备以后再做。

## 首版不做

自研编辑器、模型训练、云端多租户、自动部署任意项目、无界 Agent 递归、固定角色大会、自动吸收全部聊天作为长期记忆。Claude 订阅 OAuth 当前受官方规则阻塞，不计入首版验收。

## 成为主要开发场地的门槛

在真实仓库完成 feature 与可复现 debug，覆盖进程重启、工具中断、验证失败、审查返工和用户接管。没有重复未知副作用、覆盖原有脏改动或误报完成。记录完成率、返工、人工接管、耗时和用量；没有基线前不承诺比现有工具更快或更省。
